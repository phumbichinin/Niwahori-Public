← ↑ → で移動。↑は、掘った穴を登る実験用の操作。体力・売買はありません。

大人の方へ・比較とキーボード

方向キー / WASD：移動（下は掘る）。Space：下を掘る。Q / E：左 / 右を掘る。1 / 2：道具。R：入口へ。近くの壁をクリックして長押しでも掘れます。井戸の入口は狭いまま、地下では横穴も作れます。地形は実験版専用キーで自動保存します。
